# 収益化エージェントチーム

「地域店舗向けHP改善・集客サポートの提案レポートを作成できる営業支援Webアプリ」
（6万円受注実績あり / 提供：zari Lab）を収益化するための、Claude Code サブエージェント・チームです。

## チーム構成

| エージェント | 役割 | いつ呼ぶか |
|---|---|---|
| **monetization-strategist** | 司令塔（CRO/事業責任者） | まず最初に。価格・課金モデル・収益目標・90日プランを決め、各メンバーに作業を振る |
| **market-researcher** | 市場・競合・ターゲット調査 | 誰に売るか、相場はいくらか、勝てる切り口はどこかを知りたい時 |
| **growth-marketer** | 集客・リード獲得 | 商談数を増やす施策（営業リスト・DM/メール文面・紹介・SNS）が欲しい時 |
| **sales-proposal-writer** | 営業・提案ライティング | 提案レポート本体・無料サンプル診断・商談トーク・見積を作る時 |
| **product-monetizer** | プロダクト収益化 | 受託からSaaS/テンプレ販売/代理店へ広げる、課金機能を設計する時 |
| **landing-page-builder** | LP/Web実装 | 申込LP・無料診断フォーム導線を実際のHTMLで作る時 |

## 使い方

1. 起点はいつも **monetization-strategist**。「今あるリソースで、まず何で・いくら稼ぐか」を決めてもらう。
2. 戦略で決まったタスクを各専門エージェントに振る（strategist が誰に何を頼むか明記する）。
3. 各エージェントの成果物は `docs/` 配下にMarkdownで蓄積され、再利用できる。
4. 公開物（LP等）は `landing-page-builder` がHTMLで実装し、GitHub Pagesで公開する。

### 呼び出し例
- 「monetization-strategist を使って、90日で月20万円を目指す収益化プランを作って」
- 「market-researcher で、整体院向けに絞った競合と相場を調べて」
- 「sales-proposal-writer で、無料サンプル診断のテンプレを作って」
- 「landing-page-builder で、無料診断申込のLPを lp.html に作って」

## 設計思想
- **今月の現金を最優先**：理論より、来週商談できる相手を増やす。
- **無料サンプルレポートを共通フック**に、全チャネル・LP・商談を設計する。
- **1人で回せる運用**に落とす（自動化・テンプレ化・外注可能性を常に明記）。
- 主張には必ず「根拠/出典」または「仮定」のラベルを付ける。

詳細な初期プランは [`docs/monetization-plan.md`](../../docs/monetization-plan.md) を参照。
