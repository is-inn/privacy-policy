マイクラへの入れかた
  1. 「パックをダウンロード」を押して zombieface.mcpack を保存します。
  2. 保存したファイルをタップ → 「Minecraftで開く」を選びます。自動でパックが取り込まれます。
  3. マイクラの 設定 → ストレージ / グローバルリソース（またはワールドの「リソースパック」）から ゾンビフェイス を 有効（→側へ移動）にします。
  4. ワールドに入ると、ゾンビの顔があなたの写真になっています！🧟

※ 反映されないときは、一度マイクラを再起動してください。
