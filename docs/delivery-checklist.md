# 竹（6万円）実施チェックリスト・外注引き渡し手順書

> **使い方**：竹プラン（提案レポート＋改善実施）を受注したら、このファイルの5領域を上から順に実施する。「自分」欄はオーナー本人が判断・作成し、「外注」欄はそのままクラウドソーシング等に指示文としてコピーして渡せる粒度で書いてある。目的は1件8〜12hかかっている作業を、自分の実働3〜4h＋外注4〜5hに再配分し、実質単価を上げること。
> 前提：`docs/monetization-plan.md`（v2・飲食店特化）の松竹梅・5チェックポイントに準拠。

---

## 全体フロー（受注〜納品）

1. 受注確定 → オーナーからGBPアクセス権・写真・メニュー表を受領（下記「権限・素材の受け渡し」参照）
2. 現状棚卸し（5領域をスクショ＋簡易チェックで記録）
3. 自分が意思決定パート（カテゴリ・トーン・訴求方針・優先順位）を先に済ませる
4. 外注へ作業指示（本ファイルの「外注に出せる作業」をそのまま渡す）
5. 外注納品を自分が最終チェック
6. オーナーへ実施報告（Before/After）＋**月額継続プランをセット提案**（クロージング）

| 区分 | 目安時間 | 備考 |
|---|---|---|
| 自分（意思決定・チェック・クロージング） | 3〜4h | ここに集中することが単価UPの本質 |
| 外注（入力・加工・単純作業） | 4〜5h | 月2〜3万円の外注予算内で回す |
| 合計 | 7〜9h | 従来8〜12hから圧縮。並行作業で自分の拘束時間はさらに短縮可 |

## 権限・素材の受け渡し（最重要・事故りやすいので必読）

- **GBPオーナー権限**：店舗オーナーに「主なオーナー」または「管理者」として自分のメールアドレスを追加してもらう。**オーナー権限の完全移管は不要**（トラブル時に店舗側が制御を失うため）。
- **外注への再委任は禁止**：外注個人にGBPアカウントを直接渡さない。作業が必要な場合は自分が画面共有／代理入力するか、期間限定の「管理者」権限を外注に一時付与し、**納品後は必ず削除**する。
- **素材受け渡し**：写真・メニュー表・ロゴ等はGoogleドライブ等の共有フォルダに一括で受領し、外注にはそのフォルダのリンクのみ渡す（原本はオーナー保管のまま）。
- **契約終了・解約時**：GBP管理者権限、共有フォルダのアクセス権を速やかに剥奪する運用をあらかじめオーナーに伝えておく（信頼構築＋トラブル防止）。

## 1. GBP最適化（Googleビジネスプロフィール）

**想定効果**：検索結果での見え方が正確・魅力的になり、閲覧数・電話タップ数の底上げに直結。5領域の中で最も費用対効果が高い。

### 自分がやる要所
- [ ] カテゴリ（メイン＋サブ）の選定：競合と検索意図を見て、来店に直結するカテゴリを決める
- [ ] 差別化ポイントの言語化（投稿・説明文のトーン・訴求方針を決める）
- [ ] 投稿文（1本以上）の文面作成
- [ ] GBPオーナー権限の受け渡し交渉・受領確認

### 外注に出せる作業
- [ ] 営業時間・定休日・電話番号・住所の正確性チェックと修正入力
- [ ] 属性（バリアフリー、駐車場、支払い方法など）チェックボックスの設定
- [ ] 現状の棚卸しスプレッドシート作成（スクショ添付）
- [ ] 自分が作成した投稿文のGBPへの入力・予約公開設定

### 手順
1. GBPアクセス権を受領（上記「権限・素材の受け渡し」参照）
2. 現状棚卸し（外注）：全項目のスクショ＋現状値をシート化
3. カテゴリ・訴求方針を決定（自分）
4. 基本情報・属性を修正入力（外注）
5. 投稿文を作成（自分）→ 入力・公開（外注）

### 完了基準
- 営業時間・電話番号・住所の誤りゼロ
- カテゴリが主1＋副1以上設定済み
- 投稿が1本以上公開されている

### 所要時間目安
自分 1h ／ 外注 1h（計2h）

## 2. 写真差し替え

**想定効果**：飲食店は写真で来店可否が決まるため、5領域の中で最も来店転換への影響が大きい。1枚目（サムネ）の差し替えだけでも閲覧→ルート検索転換に効きやすい。

### 自分がやる要所
- [ ] 既存写真を精査し、使う/使わないを選別
- [ ] サムネ（1枚目）を意思決定で確定
- [ ] 撮影が必要な場合の構図ディレクション（オーナー撮影 or 立ち会い時のみ）

### 外注に出せる作業
- [ ] 写真の明るさ・トリミング補正
- [ ] リサイズ・ファイル名整理
- [ ] GBPへのアップロード作業（カテゴリ：料理／外観／内観／スタッフに分類）

### 手順
1. オーナーから写真データを受領（共有フォルダ経由）
2. 自分が選別・サムネ確定
3. 外注が補正・リサイズ・アップロード
4. 自分が最終確認（サムネの見え方をスマホで確認）

### 完了基準
- 料理・外観・内観の各カテゴリに3枚以上
- 直近半年以内の写真のみ
- サムネ1枚目が確定・反映済み

### 所要時間目安
自分 0.5h ／ 外注 1.5h（計2h）

## 3. 口コミ返信整備

**想定効果**：即効性は低いが、丁寧な返信は信頼形成に効き、月額継続（口コミ返信代行）への自然なアップセル動線になる。低評価対応はリスクが高いため自分が必ず担当。

### 自分がやる要所
- [ ] 低評価・クレーム系口コミへの個別返信文面の作成（トーン・謝意・改善姿勢が重要）
- [ ] 返信トーンガイドライン（店の雰囲気に合わせた言葉遣い）の決定

### 外注に出せる作業
- [ ] 未返信口コミの棚卸し・リスト化（星評価・投稿日・内容を一覧化）
- [ ] 高評価向け定型文（自分が作ったテンプレ）の入力・返信作業

### 手順
1. 外注が未返信口コミを全件リスト化
2. 自分が低評価・要注意口コミに個別返信を作成
3. 外注が高評価口コミにテンプレ返信を入力・投稿

### 完了基準
- 直近すべての口コミ＋過去未返信の80%以上に返信済み
- 低評価には個別文面で対応済み（テンプレ流用不可）

### 所要時間目安
自分 1h ／ 外注 1h（計2h）

## 4. メニュー訴求

**想定効果**：看板メニューが写真付きで明確に見えると、来店動機（何を食べに行くか）が具体化し、電話・予約への転換率が上がる。

### 自分がやる要所
- [ ] 看板メニュー（3品目安）の選定
- [ ] 価格の見せ方・訴求コピー（キャッチコピー含む）の作成

### 外注に出せる作業
- [ ] メニュー情報のGBP／HPへの入力作業
- [ ] メニューと写真のセット紐付け作業
- [ ] 季節・期間限定メニューの入れ替え入力

### 手順
1. オーナーからメニュー表・価格データを受領
2. 自分が看板3品とコピーを決定
3. 外注がGBP／HPへ入力、写真と紐付け

### 完了基準
- 看板メニュー3品が写真付きでGBP／HPに掲載
- 価格表記が統一されている（税込/税抜の記載ゆれがない）

### 所要時間目安
自分 1h ／ 外注 1h（計2h）

## 5. 予約導線改善

**想定効果**：改善点があっても「予約・電話まで1タップで届く」導線がないと機会損失になる。工数は小さいが取りこぼし防止として必須。

### 自分がやる要所
- [ ] 主導線を電話／ネット予約のどちらにするかの意思決定
- [ ] ボタン文言・配置の指示（例：「今すぐ電話」「空席確認」）

### 外注に出せる作業
- [ ] GBPの予約リンク設定
- [ ] HPの予約ボタンの設置・修正作業
- [ ] スマホ実機での動線チェック（何タップで到達するか記録）

### 手順
1. 自分が主導線を決定・ボタン文言を指示
2. 外注がGBP・HPへ反映
3. 外注がスマホ実機で動線を確認し、タップ数を報告
4. 自分が最終確認

### 完了基準
- GBP・HPともに1タップで予約または電話発信に到達
- スマホ実機での動線確認が完了している

### 所要時間目安
自分 0.5h ／ 外注 1h（計1.5h）

## 納品時の必須アクション（クロージング）

- [ ] Before/After（GBP画面のスクショ）を1枚のレポートにまとめてオーナーへ報告
- [ ] 報告の場で**月額継続プラン（ライト1.5万／スタンダード3万）を必ずセット提案**する
- [ ] 継続に合意が得られたら、初回の月次レポート送付日を確定する（`docs/retention-monthly-report.md`参照）
