# デイリー・チェックリスト（飲食店の提案営業）

> **あなたの設定**：目標=2件とる ／ 週3時間 ／ 引っ越し中（無理しないでOK）
> **考え方**：量で殴らない。1日ちょっとを続けるだけ。できない日は飛ばしてOK。
> 参照：`docs/proposal-template.md`（サンプルの型）／`docs/outreach-templates.md`（送る文）／`docs/sales-script.md`（商談）

---

## 使い方

- **iPhoneメモ**：下の「A. iPhoneメモ用」をコピー → メモアプリに貼る → 全選択して右上の「チェックリスト」ボタンを押すと、全部チェックボックスになる。毎朝これを見て、上から順に。
- **Notion**：下の「B. Notion用」をコピー → Notionのページに貼ると、`- [ ]` が自動でチェックボックスになる（ならない場合は貼り付け時に「マークダウンとして貼り付け」を選ぶ）。毎日リセットして使う。

---

## A. iPhoneメモ用（コピペ → 全選択 → チェックリスト化）

```
【今日の1歩・25分】
お店を1軒えらぶ（リストの続きから）
そのお店をスマホで見る（Googleマップ＋インスタ）
気づいた改善点を2〜3個メモ（写真/口コミ返信/予約導線など）
無料サンプルにその2〜3個を書く（15分）
送る（フォーム or インスタDM or メール）
トラッカーに1行記録（日付・店名・送った）

【返信が来たら（最優先で差し込み）】
お礼を返す＋「10分だけ話せますか？」と日程を聞く
商談したら松竹梅を出す（竹6万をまん中に）
その場で決まらなくても追客を1回する

【できない日】
1軒も無理なら「リストを1軒見るだけ」でOK
それも無理なら今日は休む（罪悪感ゼロ）
```

## B. Notion用（貼ると自動でチェックボックス）

### ☀️ 今日の1歩（25分・目標1軒）
- [ ] お店を1軒えらぶ（リストの続きから）
- [ ] そのお店をスマホで見る（Googleマップ＋インスタ）
- [ ] 気づいた改善点を2〜3個メモ（写真／口コミ返信／予約導線など）
- [ ] 無料サンプルにその2〜3個を書く（15分・`proposal-template.md`）
- [ ] 送る（フォーム or インスタDM or メール・`outreach-templates.md`）
- [ ] トラッカーに1行記録（日付・店名・送った）

### 📩 返信が来たら（最優先で差し込む）
- [ ] お礼を返す＋「10分だけ話せますか？」と日程を聞く
- [ ] 商談したら松竹梅を出す（竹6万をまん中に・`sales-script.md`）
- [ ] その場で決まらなくても追客を1回する

### 🌙 週1回だけ（月曜など・30分）
- [ ] 先週「送った数」と「返信数」を数える
- [ ] 返信ゼロの相手に1回だけ追客する
- [ ] 今週の目標本数を決める（引っ越し具合に合わせて無理なく）

### 😌 できない日のルール
- [ ] 1軒も無理なら「リストを1軒見るだけ」でOK
- [ ] それも無理なら休む（続けることが最優先。罪悪感ゼロ）

## 2件とるまでの地図（頭の片隅に置くだけ）

送る → 返信が来る → 話す → 竹（6万）を出す → 決まる。

- 1日1軒でも、続ければ月20〜25軒。
- ぜんぶ断られても大丈夫。**2件"YES"が出ればゴール達成**。断りは前進のサイン（数をこなしてる証拠）。
- 引っ越しが落ち着いたら1日2軒に増やす。今は「ゼロの日を減らす」だけでいい。

> あなたの強み：飲食の現場を知ってる。サンプルに"元店員だから分かる"一言を足すと、返信率が上がる。
> 例：「元・飲食店勤務です。お店の忙しさが分かるので、5分で直せる所だけまとめました」
