# 【はじめに読む】飲食店 提案営業マニュアル（全体手順書）

> このフォルダのファイルを「どういう順番で・どう使うか」をまとめた**入口**です。
> 初めての人でも、これを上から読めば全体像と手順が分かります。
> 作成：zari Lab ／ 目的：飲食店に「HP改善・集客の提案レポート」を売り、まず2件受注する。

---

## 0. これは何？（30秒で理解）

飲食店に、**無料の「お店の改善サンプル」**を送る
→ 興味を持った店と**話す（商談）**
→ **松竹梅の見積**を出して受注する（本命は「竹＝6万円」）
→ さらに**月額の継続サポート**をセットで提案して、毎月の収入にする。

やることは実質これだけ。必要な道具（テンプレ・文面・チェックリスト）は全部このフォルダに入っています。

## 1. まず押さえる3つの数字（今の設定）

- **目標**：まず2件受注する
- **使える時間**：週3時間（引っ越し中なので無理しない）
- **本命商品**：竹＝6万円（提案レポート＋改善の実施）＋ 月額1.5〜3万円の継続

## 3. 進め方（全体の流れ）

### STEP 1：準備（最初の1回だけ）
1. `step1-posting-playbook.md` を開く。
2. その手順どおり、クラウドワークス/ランサーズで**墨田区の飲食店リスト（まず50件）**を発注する。
3. `list-template.csv` をGoogleスプレッドシートにして外注さんに共有する。
   - ※リストが来るまでの間は、自分で1軒ずつ探して送り始めてOK。
   - **狙い目＝「Googleマップに載っているが自社サイトが“ない”店」**。サイト無し・SNS無し/停止・写真少・口コミ返信無 が揃うほど◎（集客に困っていて、まだ誰にも提案されていない）。
   - 自分で手集めするなら、Notionの「墨田区 飲食店リサーチ（Web/SNSなし優先）」表にためると、狙い目度でフィルタして上から送れる。

### STEP 2：毎日の営業（これがメイン・25分）
`daily-checklist.md` の順にやるだけ：
1. お店を1軒えらぶ
2. スマホでそのお店を見る（Googleマップ＋インスタ）
3. 改善点を2〜3個メモ（写真／口コミ返信／予約導線 など）
4. `proposal-template.md` の型に、その2〜3個を書いて**無料サンプル**を作る（15分）
5. `outreach-templates.md` の文面で**送る**（フォーム/DM/メール）
6. `outreach-tracker.md` に1行記録する

### STEP 3：返信が来たら（最優先）
1. お礼を返し「10分だけ話せますか？」と日程を聞く。
2. 話すときは `sales-script.md` を見ながら。
3. `quotation-and-upsell.md` の松竹梅を出し、**竹（6万円）**をまん中に。
4. 受注できたら、締めで**月額**もセット提案する。

### STEP 4：受注できたら（実施）
1. `delivery-checklist.md` の手順で改善を実施（一部は外注に回せる）。
2. 月額契約になったら、毎月 `retention-monthly-report.md` の型でレポートを出す（継続してもらうため）。

---

## 4. うまくいかない時のヒント

- **返信が来ない** → まず「送った数」を増やす。断られても正常（数の勝負）。文面は `outreach-templates.md` の別チャネル（DM/メール）も試す。
- **時間がない日** → 「リストを1軒見るだけ」でOK。ゼロの日を減らすのが目的。
- **何を書けばいいか迷う** → `proposal-template.md` の記入例（炭火焼鳥 とり松）をそのまま真似る。
- **強み**：あなたは飲食店で働いた経験がある。「元・飲食店勤務です」の一言を添えると信頼されやすい。

## 5. 数字の目安（気にしすぎない）

- 1日1軒でも、続ければ月20〜25軒。
- ぜんぶ断られても大丈夫。**2件YESが出ればゴール**。
- 引っ越しが落ち着いたら1日2軒に増やす。
