# 月額継続の解約防止：月次レポートの型

> **使い方**：月額継続プラン（ライト1.5万／スタンダード3万）契約者に、毎月同じ日にこのテンプレを埋めて送付する。目的は「機能追加」ではなく「解約されない導線」を作ること。1回の作成は30分以内で終わる設計にしてある。
> 前提：`docs/monetization-plan.md`（v2）の月額継続プラン、`docs/delivery-checklist.md`の実施ログを流用する。

---

## レポート構成（この3ブロック固定）

1. **今月やったこと**（実施ログの要約、写真つきが理想）
2. **数字の変化**（先月比：GBP閲覧・電話・ルート検索・口コミ数/評価）
3. **来月の提案**（1〜2個、次月作業の伏線＝継続の必然性を作る）

---

## 記入例（架空店舗：定食屋「まる屋」様・スタンダードプラン）

```
━━━━━━━━━━━━━━━━━━━━
月次レポート ／ まる屋 様
対象期間：2026年6月
━━━━━━━━━━━━━━━━━━━━

■ 1. 今月やったこと
・GBP投稿：4回（週替わり定食の告知）
・口コミ返信：8件対応（低評価1件含む）
・写真更新：5枚（料理3・内観2）
・その他：HPのランチメニューページを最新価格に更新

■ 2. 数字の変化（先月比）
| 指標 | 先月 | 今月 | 増減 |
|---|---|---|---|
| GBP閲覧数（検索＋マップ合計） | 1,240 | 1,460 | +17.7% |
| 電話タップ数 | 22 | 29 | +31.8% |
| ルート検索数 | 58 | 71 | +22.4% |
| ウェブサイトクリック数 | 34 | 40 | +17.6% |
| 口コミ件数（累計） | 47 | 51 | +4件 |
| 平均評価 | 4.3 | 4.4 | +0.1 |

ひとことコメント：
「週替わり定食の投稿を始めてから、電話タップ数が大きく伸びました（+31.8%）。ランチタイム前の投稿が特に反応が良い傾向です。」

■ 3. 来月の提案
・提案1：ディナーメニューの写真がまだ少ないため、来月は夜の店内・料理写真を追加更新したいです。
・提案2：低評価の口コミ1件について、返信後の再来店を狙い、次回来店時のクーポン案内も検討しませんか。

━━━━━━━━━━━━━━━━━━━━
```

## 運用手順（月1回・30分で作る）

1. **GBPインサイトを開き数値を記録**（5分）：閲覧数・電話タップ・ルート検索・クリック数をコピー
2. **先月シートに追記、増減を計算**（5分）：スプレッドシートに自動計算式を入れておくと毎月ここは1分で終わる
3. **今月やったこと3〜5項目をピックアップ**（5分）：`delivery-checklist.md`運用時の実施ログ／投稿履歴からそのまま転記
4. **伸びた指標にコメントを1〜2文**（5分）：数字と施策を因果で結びつける（因果が言えない月は「継続観察中」でよい、無理にこじつけない）
5. **来月の提案を1〜2個書く**（5分）：今月の気づき・未着手項目から選ぶ
6. **PDF化 or レポートテンプレに流し込み送付**（5分）：毎月同じ曜日・時間に固定送付

---

## 解約防止の設計ポイント（各項目に想定効果）

| 設計要素 | 想定効果 |
|---|---|
| 数字を毎月定量で見せる | 効果が可視化され、感覚ではなく根拠で解約を思いとどまらせる |
| 「来月の提案」を必ず入れる | 単月で完結させず「まだやることがある」状態を作り、継続の必然性を持たせる |
| 一番伸びた指標をハイライト | オーナーの成功体験を強調し、担当者・サービスへの信頼を強化する |
| 送付タイミングを毎月固定 | ルーティン化により解約検討のタイミングそのものを生じにくくする |
| 実施ログを毎月蓄積して残す | 解約検討時に「これだけやってもらった」という引き止め材料・比較優位になる |
| 低評価対応など見えにくい作業も明記 | 「レポートに出ない裏側の仕事」を可視化し、価格への納得感を維持する |

## コンバージョン導線図（無料→有料、フロー→月額）

```
[無料サンプル提案レポート（1枚・5チェック項目）]
        │  ← ここが唯一の入口。価値が一瞬で伝わることを最優先
        ▼
      [商談]
        │
   ┌────┼─────┐
   ▼    ▼     ▼
 梅3.5万 竹6万★ 松12万〜
（実施なし）（本命：提案＋実施）（実施＋1ヶ月フォロー）
        │
        │  ← 納品時に必ずセット提案（delivery-checklist.md 末尾）
        ▼
 [月額継続プラン提示]
   ┌────┴─────┐
   ▼           ▼
ライト1.5万    スタンダード3万★
        │
        ▼
 [月次レポート送付（毎月固定日・30分で作成）]
   → 数字の変化を見せる（解約防止）
   → 来月の提案（継続の必然性）
        │
        ├─→ 継続（LTV蓄積）
        └─→ アップセル（ライト→スタンダード／竹の再受注）
```
