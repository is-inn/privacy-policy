# 飲食店リスト作成 外注指示書（クラウドワークス/ランサーズ想定）

> **使い方**：このままクラウドワークス/ランサーズの「タスク・軽作業」または「プロジェクト（データ入力）」で発注する。§6の募集文をコピペし、エリアだけ自分の営業エリアに書き換えて投稿する。納品はスプレッドシート（Googleスプレッドシート共有 or Excel）で受け取る。
>
> 参照：`docs/monetization-plan.md`（v2）の施策1「飲食店リスト作成（外注・月1〜1.5万円想定）」に対応。

---

## 1. 目的

「無料サンプル提案レポート」を送る先＝アウトバウンド対象の飲食店リストを200件、外注で作成する。週20件送付ペースで約10週間分のストックになる（90日プラン：送付180件に対応）。自分は診断・商談に集中するため、リスト抽出とデータ入力は外注に任せる。

---

## 2. 抽出条件（エリア × 業態）

### エリア
- **{対象エリア}**（例：東京都○○区・△△区・□□区、または「渋谷区・目黒区・世田谷区の一部」など、自分が土地勘・移動しやすい範囲を1〜3エリアに絞る）
- 訪問しなくても商談できる想定だが、将来の対面訪問・実績づくりのため無理なく回れる範囲を推奨。

### 業態（個人〜小規模の独立系飲食店に絞る）
- 対象：居酒屋、カフェ・喫茶、ラーメン・そば・うどん、焼肉・焼鳥、和食・寿司、イタリアン・洋食、中華、バー、定食・食堂
- 規模の目安：**1〜3店舗運営の個人店・小規模チェーン**（オーナーに提案が届きやすい規模）
- 客単価の目安：1,500円〜6,000円程度（6万円の提案が投資として現実的に検討できる水準）

### 必須条件（すべて満たすもののみ収集）
1. **Googleビジネスプロフィール（GBP）が存在する**、または**自社ホームページがある**（診断・サンプル作成の材料になるため必須）
2. **連絡先が1つ以上取得できる**：電話番号／問い合わせフォームURL／Instagram DM可能なアカウント のいずれか
3. 現在**営業中**であることが確認できる（GBPの「営業中」表示、直近の投稿・口コミがある等）

---

## 3. 除外条件

以下は収集対象から**除外**する：

- 全国チェーン・大手フランチャイズ（独自のマーケティング部門があり、オーナー個人に提案が届かない）
- GBPもホームページも存在しない店舗（診断・サンプルが作れない）
- 電話・フォーム・Instagramのいずれの連絡先も見つからない店舗
- 閉業・休業中と明記されている店舗
- 直近の口コミ・投稿が1年以上前で更新が完全に止まっている店舗（活動実態が薄い）
- 同一店舗・同一グループの重複エントリ

## 4. スプレッドシートのカラム定義

納品は以下の列を持つGoogleスプレッドシート（1シート200行）で受け取る。

| 列 | 項目名 | 内容・入力ルール |
|---|---|---|
| A | No. | 連番（1〜200） |
| B | 店名 | 正式名称をそのまま |
| C | 業態 | 上記業態リストから1つ選択（複数該当時は主たるもの） |
| D | エリア（市区町村） | 例：渋谷区 |
| E | 住所 | GBP/HP記載の住所をそのままコピー |
| F | GBPリンク | Googleマップの店舗URL |
| G | GBP評価点数 | 例：4.2（未掲載なら空欄） |
| H | GBPレビュー数 | 例：87件 |
| I | HP有無 | あり／なし |
| J | HP URL | あれば記入 |
| K | Instagramアカウント | @から始まるID（あれば） |
| L | Instagram URL | あれば記入 |
| M | Instagramフォロワー数 | あれば概算 |
| N | 電話番号 | ハイフンあり形式 |
| O | 問い合わせフォームURL有無 | あり／なし |
| P | 問い合わせフォームURL | あれば記入 |
| Q | 推奨連絡手段 | フォーム／インスタDM／電話 のうち最も反応しやすそうなもの1つ（Rの理由と合わせて記入） |
| R | 推奨理由メモ | 例：「フォームなし、インスタ更新頻度高いのでDM向き」 |
| S | 営業時間・定休日の記載有無 | あり／なし／一部のみ |
| T | 写真点数の印象 | 多い／普通／少ない（GBP掲載写真をざっと見た主観でOK） |
| U | 直近の口コミ返信状況 | あり／なし／一部 |
| V | 備考 | その他気づいた点（自由記述） |
| W | 抽出日 | YYYY/MM/DD |
| X | 抽出担当者 | 記入者名 |

## 5. 品質チェック方法（納品後、自分が15〜20分で実施）

1. **ランダムサンプリング検査**：納品200件のうち**無作為に10%（20件）**をピックアップし、GBPリンク・HP URL・電話番号・フォームURLを実際にクリック／発信確認して疎通するか確認。
2. **必須項目の空欄チェック**：F〜Xのうち「電話番号／フォームURL／Instagram URL」が**すべて空欄**の行がないかフィルタで確認（1つでも連絡先があればOK）。
3. **重複チェック**：B列（店名）+ E列（住所）でGoogleスプレッドシートの「重複を削除」機能相当のチェックをかけ、重複がないか確認。
4. **エリア・業態の条件一致確認**：D列・C列が発注時の条件範囲内に収まっているかフィルタで確認。
5. 不備が10%（20件）を超える場合は差し戻し、無償の再修正を依頼する（発注文にもその旨明記）。

---

## 6. 想定単価・納期

- **想定予算**：合計 12,000〜15,000円（1件あたり60〜75円換算）※月の外注予算1〜1.5万円の範囲内
- **納期**：発注確定から**5営業日**
- **納品形式**：Googleスプレッドシート（編集権限を共有）またはExcel（.xlsx）
- **分割発注も可**：まず50件（3,000〜4,000円・2営業日）で試験発注し、品質を確認してから残り150件を追加発注する方法も推奨（初回外注の実効性検証を兼ねる）。
