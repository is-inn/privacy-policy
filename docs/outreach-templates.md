# アウトバウンド文面テンプレ集（飲食店向け）

> **使い方**：{店名}{業態}{エリア}{気づいた改善点} を該当店舗の情報に置き換えてそのまま送信する。{気づいた改善点}は事前にGBP/HP/Instagramを3〜5分ざっと見て見つけた1点（GBP・写真・口コミ返信・メニュー訴求・予約導線の5チェックのいずれか）を入れる。詳細は `docs/monetization-plan.md` §4の5チェックポイントを参照。
>
> 送付運用のフロー・記録方法は `docs/outreach-tracker.md` を参照。

---

## 0. 全チャネル共通：返信率を上げる型

| 要素 | 型 | ねらい |
|---|---|---|
| 件名（メール系） | 「{店名}様｜GBPを拝見し、無料で改善点をまとめました」 | 具体名を入れて「自分宛」感を出す。営業感の強い単語（提案／集客／SEO）を避ける |
| 書き出し | 先に「見た事実」を1文で示す（例：「貴店のGoogleマップを拝見しました」） | 定型文の一斉送信ではないと伝わる |
| 本題 | 気づいた改善点を**1つだけ**具体的に指摘（欲張らない） | 情報過多を避け、返信のハードルを下げる |
| フック | 「無料サンプル提案レポート」を提示（費用・勧誘感を出さない） | 実演で信頼を作り、警戒心を下げる |
| CTA | Yes/Noで即答できる質問形（「詳しく見てみたい」等）＋返信不要で受け取れる導線も用意 | 返信の心理的ハードルを最小化 |
| 送信者情報 | 実名＋屋号（zari Lab）＋実績（飲食店で6万円のご支援実績）を一言添える | 実在性・信頼の担保 |

## 1. 問い合わせフォーム営業

**チャネル特性**：一斉送信感が出やすく警戒されやすい反面、店舗側フォームは担当者が必ず目を通す傾向があるため一定の到達率がある。

**想定反応率の仮説**：返信率 8〜12%（`monetization-plan.md`の返信率10%想定に近い。フォームは定型文と判断されやすく、インスタDMよりやや低いと仮定）

### 初回送付文面

```
件名：{店名}様｜Googleビジネスプロフィールを拝見し、無料で改善点をまとめました

{店名} ご担当者様

突然のご連絡失礼いたします。
飲食店の集客・Web改善のご支援をしております、zari Lab（栗原）と申します。

貴店のGoogleビジネスプロフィール（Googleマップ）を拝見したところ、
{気づいた改善点}という点が少しもったいないと感じました。
{業態}のお店ですと、ここを直すだけでも来店のきっかけが増えるケースが多いです。

現在、{エリア}周辺の飲食店様向けに、無料でサンプルの改善提案レポート
（Googleマップ・写真・口コミ返信・メニューの見せ方・予約導線を
チェックし、すぐ直せる点をまとめたもの）を作成しております。

もしよろしければ、貴店専用の無料サンプルレポートをお送りしますが、
ご興味はございますでしょうか？（費用は一切かかりません）

ご不要でしたら本メールは読み流していただいて構いません。
ご興味があれば「見てみたい」とだけ一言ご返信いただければ、
数日内にお送りいたします。

--
zari Lab　栗原
飲食店様のGoogleマップ・HP改善のご支援（実績：飲食店様への提案・改善実施 6万円でのご支援実績あり）
```

## 2. インスタDM

**チャネル特性**：オーナー・店長本人が直接運用しているケースが多く、カジュアルな言葉遣いなら警戒されにくい。文章は短く、スマホで3秒で読める長さにする。

**想定反応率の仮説**：返信率 10〜15%（フォームより高いと仮定。オーナー本人に直接届き、カジュアルなトーンが刺さりやすいため。ただし要検証＝初月にA/Bで実測する）

### 初回DM

```
はじめまして、{エリア}で飲食店さんのGoogleマップ・SNS改善のお手伝いをしているzari Labの栗原と申します！

{店名}さんの投稿拝見しました、{気づいた改善点}のがちょっともったいないなと思ってご連絡しました🙏

今、無料で{店名}さん専用の改善サンプル（Googleマップの写真・口コミ返信・メニューの見せ方とかをチェックしたもの）をお作りできるんですが、良ければ見てみますか？

費用は一切かからないので、気軽に「見てみたい」だけ返信もらえたら嬉しいです！
```

### 追客1（3〜4日後、未読/未返信時）

```
連投すみません、栗原です🙏
お忙しいと思うので短めに！

{業態}のお店だと{気づいた改善点}を直すだけで反応変わることが多いので、無料サンプルだけでも良ければ送ります。
不要なら全然スルーしてもらって大丈夫です！
```

### 追客2（1週間後、最終）

```
何度もすみません、今回はこれで最後にしますね！

もし今後Googleマップやインスタの見え方で気になることが出てきたら、いつでもDMください。
{店名}さんの投稿、これからも見させてもらいます📸
```

## 3. 電話後フォローメール

**前提**：電話で一度会話（担当者不在の場合含む）した後、興味を示された、または「メールで送って」と言われたケースで使う。すでに接点があるため最も温度が高いチャネル。

**想定反応率の仮説**：返信率・商談化率ともに 20〜30%（電話で一次接触済みのため、フォーム/DM単体より大幅に高いと仮定。ただし電話自体の接続率・アポ取得率は別途要計測）

### 送付文面（電話直後、当日中に送る）

```
件名：本日お電話しました{店名}様｜無料サンプルレポートをお送りします

{店名} ご担当者様

本日はお電話にてお時間をいただき、ありがとうございました。
zari Lab（栗原）でございます。

お話しした通り、貴店のGoogleビジネスプロフィールを拝見し、
{気づいた改善点}という点を中心に、無料の改善提案サンプルをお送りいたします。
（添付／下記リンクをご確認ください）

サンプルの内容は以下の5点をチェックしたものです。
・Googleビジネスプロフィール（営業時間・カテゴリ・投稿頻度など）
・お写真の見せ方
・口コミへの返信状況
・メニューの訴求方法
・ご予約への導線

もしご覧になって「もう少し詳しく聞きたい」ということでしたら、
30分ほどオンラインまたはお電話でご説明のお時間をいただけますと幸いです。
下記日程でご都合いかがでしょうか。

・{候補日時1}
・{候補日時2}
・{候補日時3}

上記以外でもご都合の良い日時があればお知らせください。

zari Lab　栗原
（飲食店様のGoogleマップ・HP改善支援　実績：提案＋改善実施6万円でのご支援実績あり）
```
