# アウトバウンド送付トラッカー設計（1日30分運用）

> **使い方**：この設計どおりにGoogleスプレッドシートを1つ作る（シート1「送付ログ」＋シート2「週次サマリ」）。毎営業日30分、下記フローに沿って送付・記録する。文面は `docs/outreach-templates.md`、送付先リストは `docs/list-outsourcing-brief.md` で作成した外注リストを使う。

---

## 1. 全体像

目標：週20件送付（`monetization-plan.md`の90日プランに対応：30日=60件、90日=180件）。
先行指標として、この5つだけを毎週追う。

| # | 指標 | 定義 | 30日目標 | 90日目標 |
|---|---|---|---|---|
| 1 | 送付数 | 週にフォーム/DM/電話で新規接触した件数 | 週15件（累計60件） | 週20件（累計180件） |
| 2 | 返信率 | 返信数 ÷ 送付数 | 10% | 10% |
| 3 | 商談化率 | 商談実施数 ÷ 送付数（累計ベース） | 10%（送付10→商談1） | 10% |
| 4 | フロー成約率 | フロー成約数（梅/竹/松） ÷ 商談実施数 | 30〜35% | 30〜35% |
| 5 | 月額アップセル率 | 月額成約数 ÷ フロー成約数 | 60〜70% | 60〜70% |

> 参考補助指標（診断用）：**返信→商談転換率**（商談実施数 ÷ 返信数）も併せて見る。ここが極端に低い場合は「返信はあるが日程調整で離脱している」ことを意味し、返信対応の速度・文面を見直すサイン。

---

## 2. スプレッドシート設計

### シート1：送付ログ（1行＝1店舗1アプローチ）

| 列 | 項目名 | 入力ルール |
|---|---|---|
| A | No. | 連番 |
| B | 送付日 | YYYY/MM/DD |
| C | 店名 | リストからコピー |
| D | 業態 | リストからコピー |
| E | エリア | リストからコピー |
| F | チャネル | フォーム／インスタDM／電話後メール |
| G | 文面バージョン | A／B（複数パターンをテストする場合） |
| H | 気づいた改善点（送付文に入れた内容） | GBP／写真／口コミ返信／メニュー訴求／予約導線 のどれか＋一言メモ |
| I | ステータス | 送付済み／反応あり／日程調整中／商談実施／提案済み／成約／月額成約／失注／保留 |
| J | 返信日 | あれば記入 |
| K | 返信内容メモ | 一言でOK（例：「興味あり、来週電話希望」） |
| L | 商談日 | あれば記入 |
| M | 商談結果 | 前向き／様子見／見送り |
| N | 成約プラン | 梅（3.5万）／竹（6万）／松（12万〜）／なし |
| O | フロー成約金額 | 実額 |
| P | 月額成約有無 | あり（ライト1.5万／スタンダード3万）／なし |
| Q | 月額金額 | 実額 |
| R | 次アクション | 例：「3日後に追客1を送る」 |
| S | 次アクション予定日 | YYYY/MM/DD（この日をトリガーに動く） |

### シート2：週次サマリ（週1行、シート1から手動またはCOUNTIF/SUMIFで集計）

| 列 | 項目名 | 算出方法 |
|---|---|---|
| A | 週（開始日） | 例：2026/07/20週 |
| B | 送付数 | シート1のB列（送付日）で当該週をカウント |
| C | 返信数 | シート1のI列が「反応あり」以降のステータスで当該週送付分をカウント |
| D | 返信率 | C ÷ B |
| E | 商談実施数（累計） | シート1のI列「商談実施」以降のステータス数（累計） |
| F | 商談化率（累計） | E ÷ 累計送付数 |
| G | フロー成約数（累計） | シート1のN列に梅/竹/松が入っている行数（累計） |
| H | フロー成約率 | G ÷ E |
| I | 月額成約数（累計） | シート1のP列「あり」の行数（累計） |
| J | 月額アップセル率 | I ÷ G |
| K | 気づき・来週の改善アクション | 自由記述（下記§4の見方に沿って書く） |

## 3. 1日30分の運用フロー（平日ルーティン）

前提：週20件送付を平日5日で回すため、1日あたり新規4件を目安にする。

| 時間 | やること |
|---|---|
| 0〜5分 | 前日までの返信・DMをチェック。返信があればシート1のI〜K列を更新し、追客テンプレ（`outreach-templates.md`）に沿って即返信 |
| 5〜10分 | シート1「次アクション予定日」が今日の行を確認し、追客1／追客2を該当分だけ送付 |
| 10〜25分 | リストから新規4件を選定 → 各店のGBP/HP/インスタを3〜5分でざっと見て「気づいた改善点」を1つ決める → プレースホルダを埋めてチャネル別テンプレを送付（1件あたり3〜4分） |
| 25〜30分 | シート1に本日送付した4件（B〜I列、H列）を記入。週の途中（毎週金曜）はシート2の週次サマリも更新 |

> 反応があり「詳しく見たい」と返信が来た店舗については、この30分ルーティンとは別枠で**15分**を使い、`monetization-plan.md` §4の5チェック項目に沿った本格的な無料サンプルレポートをアプリで作成し、電話後フォローメールのテンプレで送付する（実演型の商談化ステップ）。

---

## 4. 週次の見方（毎週月曜、10分でレビュー）

シート2の最新行を見て、以下の分岐で来週のアクションを決める。

1. **送付数が目標未達（週20件に届かない）**
   → リストの残数を確認。残数が少なければ `list-outsourcing-brief.md` の追加発注（残150件など）を検討。
2. **返信率が5%未満**
   → 文面（件名・気づいた改善点の具体性）を見直す。チャネル別（フォーム/DM/電話後）で返信率に差がないか比較し、低いチャネルの比重を下げる。
3. **返信率は目標並みだが商談化率が低い（返信→商談の転換が悪い）**
   → 返信への一次対応スピードを確認（当日中に返せているか）。日程提示の仕方（候補日時を先に3つ出す等）を見直す。
4. **商談化率は良いがフロー成約率が30%未満**
   → 商談トークスクリプト・松竹梅の見せ方（`sales-proposal-writer`が作成する台本）を見直す。
5. **フロー成約はあるが月額アップセル率が60%未満**
   → クロージング時に月額をセットで提案できているか確認。提案タイミング（フロー契約書サイン時に必ず提示）を徹底する。

毎週この5分岐のどれに当てはまるかをシート2のK列に一言メモし、翌週の30分ルーティンに反映する。
