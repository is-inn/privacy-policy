# ステップ1 実行手順書：飲食店リスト200件を外注発注する

> このファイルの通りに上から進めれば、リスト外注の発注が完了します。所要 約30分。
> 参照：`docs/list-outsourcing-brief.md`（詳細条件）／`docs/list-template.csv`（納品ひな型）

---

## 対象エリア（確定済み）

- **対象エリア：墨田区**
  - 募集文・スプレッドシート名に反映済み。将来広げる場合は隣接エリア（江東区・台東区など）を追加する。

---

## 手順（上から順に）

### ① 納品用スプレッドシートを用意する（5分）
1. `docs/list-template.csv` をGoogleドライブにアップロード → 右クリック →「Googleスプレッドシートで開く」。
2. ファイル名を「飲食店リスト_墨田区_200件」に変更。
3. 2行目のサンプル行（炭火焼鳥 とり松）は**残しておく**（記入例として外注者に見せる）。実データは3行目から。
4. 右上「共有」→「リンクを知っている全員」→権限「**編集者**」にしておく（発注確定後に受注者へURLを渡す）。

### ② クラウドソーシングに募集を出す（10分）
1. クラウドワークス または ランサーズ にログイン（無ければ無料登録）。
2. 「新しい仕事を依頼」→ カテゴリ「データ入力・リスト作成」を選択。
3. **タイトル**（下記コピペ）と**募集文**（下記コピペ）を貼る（墨田区で確定済み・置換不要）。
4. 報酬・人数を設定：**まず50件で試験発注（3,000〜4,000円・2営業日）**を推奨。品質を確認してから残り150件を追加発注。
5. 「①で作ったスプレッドシートに直接入力してください。URLは発注確定後にお渡しします」と記載（テンプレ内に記載済み）。
6. 公開。

### ③ 受注者を選ぶ（応募後・5分）
- 応募者のうち、**データ入力/リサーチ実績があり評価の高い人**を優先。
- 選定したら、①のスプレッドシートURL（編集者権限）をメッセージで送付。

### ④ 納品後の品質チェック（納品後・15〜20分）
`docs/list-outsourcing-brief.md` §5の通り：
1. 無作為に20件、GBP/HP/電話/フォームのリンクが疎通するか確認。
2. 連絡先がすべて空欄の行がないかフィルタで確認。
3. 店名＋住所で重複チェック。
4. エリア・業態が条件内か確認。
5. 不備が20件超なら差し戻し（無償修正・募集文に明記済み）。

### ⑤ 次のアクションへ
- リストが揃ったら → `docs/outreach-templates.md` ＋ `docs/proposal-template.md` で**週20件のサンプル送付**を開始。
- 送付の記録は `docs/outreach-tracker.md` のトラッカーで。

・Googleマップ検索やSNS検索に慣れている方
・データ入力・リサーチ作業のご経験がある方
・丁寧な作業をしていただける方

ご質問やお見積りのご相談があればお気軽にメッセージください。
よろしくお願いいたします。
