## 記入例（1件・そのまま参考にできる完成サンプル）

**炭火焼鳥 とり松 様　無料ミニ診断レポート**

はじめまして。世田谷エリアの飲食店さんのGoogle・HP集客をお手伝いしている zari Lab です。
とり松様のGoogleページとホームページを拝見し、今すぐ直せて来店に効く点を5分でまとめました。

### 気づいた点（優先度の高い順）

**① 写真：1枚目（サムネ）を看板メニューに差し替える**
- 今どうなっているか：Googleの1枚目が「店の外観（夜・暗め）」。料理写真は5枚目以降に埋もれている。
- こう変える：1枚目を「炭火で焼いている串の寄り写真（湯気あり）」に変更。外観は3枚目へ。
- なぜ効くか：飲食は1枚目で入店が決まる。検索一覧で料理が出るだけでクリック率が上がり、月の来店が数組増えるだけで元が取れる（客単価4,000円×月8組増＝月3.2万円）。

**② GBP：営業時間に「定休日（水曜）」が未設定で、水曜に来店ロスが出ている**
- 今どうなっているか：定休日が空欄。「営業中」と誤表示され、水曜に来て閉まっていた口コミが1件ある。
- こう変える：定休日=水曜、L.O.=22:30を正確に登録。臨時休業は都度「特別営業時間」で反映。
- なぜ効くか：ムダ足による低評価と信頼低下を防げる。損を防ぐ改善。

**③ 口コミ返信：直近12件のうち返信ゼロ。★3の指摘に無反応**
- 今どうなっているか：★5にも★3にも返信がなく、放置に見える。
- こう変える：まず直近全件に返信。★3の「提供が遅い」には謝意＋改善姿勢を1文で。
- なぜ効くか：返信がある店は「ちゃんとした店」に見え、迷っている客の後押しになる。Googleの評価順位にも好影響。

**④ メニュー訴求：看板の「名物せせり」がどこにも大きく出ていない**
- こう変える：GBPの「メニュー」と投稿、HPトップに「名物せせり 1本190円」を写真つきで最上段に。

### 特に、今日中でも直せる1つ
写真の1枚目差し替え。ここだけでも来店クリックが増えます。

### この続き（あと2個あります）
予約ボタンの位置と、限定メニューの打ち出し方に、とり松様向けの改善案があと2個あります。
どれから直すと一番早く客足が増えるか、優先順位つきで15分でご説明します。今週10分お電話いただけませんか？

# 【B】本番提案レポート 章立てテンプレ（竹6万円想定・清書用）

> サンプルで反応が出た店に出す正式版。5チェックを「課題→改善→効果→プラン→次の一歩」の流れで通す。価格ページの直前に必ず「価値の要約」を置く。

### 表紙
- タイトル：`{店名} 様　集客改善のご提案`
- サブ：Googleと写真を整えて、来店を増やす／作成日／zari Lab

### 1. 現状のまとめ（課題の合意）
5チェックを一覧化。各項目を「現状の弱点 → 放置した場合の損」で1〜2行。
| 項目 | 現状 | このままだと |
|---|---|---|
| GBP/MEO | {現状の弱点} | {失う来店・信頼} |
| 写真 | {現状の弱点} | {クリック機会の損} |
| 口コミ返信 | {現状の弱点} | {迷い客の離脱} |
| メニュー訴求 | {現状の弱点} | {看板が伝わらない} |
| 予約導線 | {現状の弱点} | {予約前の離脱} |

### 2. 改善提案（この箇所を、こう変える）
項目ごとに「Before（現状）／After（変更後）／作業内容」を具体で。写真は差し替え候補まで指定。

### 3. 期待できる効果（試算）
- 客単価 `{客単価}` 円 × 月の増加来店 `{増加組数}` 組 ＝ 月 `{推定効果}` 円の売上増。
- 記入例：客単価4,000円 × 月8組増 ＝ 月3.2万円増。6万円の投資は約2ヶ月で回収、以降は増益。
- 「損を防ぐ」効果（定休日誤表示の解消、低評価の抑制）も併記。

### 4. 実施プランと費用（松竹梅）
| プラン | 費用 | 内容 |
|---|---|---|
| 梅 | 3.5万円 | 提案レポートのみ（改善点と優先順位。実施なし） |
| 竹 ★おすすめ | 6万円 | レポート＋主要改善の実施（GBP最適化・写真差し替え・口コミ返信整備・予約導線改善） |
| 松 | 12万円〜 | 竹＋1ヶ月運用フォロー（効果測定・微修正）＋初月の月額サポート込み |

### 5. 次のステップ
1. 本提案でプラン決定（竹がおすすめ）　2. 着手（GBP編集権限の共有）　3. 約{日数}日で実施完了・ご報告
そして：**「作って終わり」にしないための月額継続サポート**（別紙見積参照）を最後に一言添える。

改善は入れて終わりではなく、写真・口コミ・投稿を毎月手入れするほど順位と来店が伸びます。月額プラン（ライト1.5万／スタンダード3万）で伴走します。詳細は商談で。
